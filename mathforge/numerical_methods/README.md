# Numerical Methods Module

> Root-finding, integration, and interpolation algorithms.

## Overview
Provides algorithms for solving problems that don't have closed-
form solutions — finding where a function crosses zero, estimating
integrals, interpolating between known points.

## Scope
Responsible for: root-finding (bisection, Newton-Raphson, secant),
numerical integration (trapezoidal, Simpson's rule), interpolation.

Not responsible for: symbolic calculus (exact derivatives/integrals
belong to a future Calculus module), linear algebra internals.

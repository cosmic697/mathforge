# Statistics Module

> Descriptive statistics and regression for MathForge.

## Overview
Provides a Dataset object wrapping a collection of numeric
observations, with descriptive statistics and basic regression.

## Scope
Responsible for: mean, median, mode, variance, standard deviation,
correlation, covariance, simple linear regression.

Not responsible for: probability distributions (separate future
concern), numerical methods, linear algebra internals (though
Dataset may use Vector internally).

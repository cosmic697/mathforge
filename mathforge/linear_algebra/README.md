# Linear Algebra Module

> Vectors, matrices, and related operations for MathForge.

## Overview
Provides vector and matrix objects with operations needed across
MathForge — geometry, graphing, statistics, numerical methods.

## Scope
This module is responsible for: Vector, Matrix, decomposition
(Gaussian elimination, LU, QR), eigenvalues/eigenvectors, SVD.

This module is NOT responsible for: symbolic algebra, calculus,
graph rendering.
